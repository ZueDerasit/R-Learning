# 05 Statistical Analysis

This section introduces statistical analysis in R, from descriptive statistics and probability concepts to hypothesis testing, correlation, group comparisons, regression analysis, and model diagnostics.

## Objectives

The objectives of this section are to:

- Describe and summarise data using appropriate statistical measures
- Understand probability and common probability distributions
- Construct and interpret confidence intervals
- Perform and interpret hypothesis tests
- Measure relationships between variables
- Compare groups using statistical tests
- Analyse categorical data
- Perform analysis of variance
- Build linear and logistic regression models
- Assess statistical model assumptions and diagnostics
- Interpret statistical results in a meaningful way

## Topics Covered

| File | Topic |

| `01_Descriptive-Statistics.R` | Measures of centre, spread, and descriptive summaries |
