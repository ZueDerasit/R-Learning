# Data Visualization

This section covers the principles and techniques used to visualise data in R.

The main goal is to transform data into clear and meaningful graphical representations that help reveal patterns, distributions, relationships, and trends.

---

## Learning Objectives

By completing this section, I should be able to:

- Create basic statistical plots in R
- Understand the purpose of different types of graphs
- Visualise distributions of variables
- Compare groups and categories
- Examine relationships between variables
- Visualise trends over time
- Create publication-quality graphics
- Choose an appropriate visualisation for a statistical question
