# Data Import & Inspection

This section covers the basic workflow of importing and inspecting data in R before performing data manipulation and statistical analysis.

The main goal is to understand the structure, content, and quality of a dataset before analysing it.

---

## Learning Objectives

By completing this section, I should be able to:

- Import data into R
- Understand the structure of a dataset
- Inspect variables and observations
- Check data types
- Identify missing values
- Check for duplicate observations
- Obtain basic summaries of variables
- Identify potential data quality issues



The general workflow is:

Import Data
     ↓
Inspect Structure
     ↓
Check Variables
     ↓
Check Data Types
     ↓
Check Missing Values
     ↓
Check Duplicates
     ↓
Check Data Quality
     ↓
Prepare for Data Manipulation
