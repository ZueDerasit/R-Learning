# 06 Advanced Statistical Methods

This section introduces advanced statistical methods commonly used for research, multivariate analysis, time series, econometrics, and statistical modelling.

## Objectives

The objectives of this section are to:

- Apply multivariate statistical methods
- Reduce the dimensionality of high-dimensional data
- Identify underlying structures in observed variables
- Analyse relationships among multiple variables
- Model and forecast time-dependent observations
- Analyse multivariate time series
- Understand panel data models
- Apply nonparametric statistical methods
- Perform statistical inference using resampling methods
- Connect statistical methodology with real research problems
