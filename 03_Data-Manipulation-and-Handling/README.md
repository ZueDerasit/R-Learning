# Data Manipulation & Handling

This section covers the process of cleaning, transforming, organising, and preparing data in R for statistical analysis.

The main goal is to transform raw data into a clean and analysis-ready dataset.

---

## Learning Objectives

By completing this section, I should be able to:

- Select and filter observations and variables
- Create and transform variables
- Sort and arrange data
- Group and summarise data
- Handle missing data appropriately
- Clean inconsistent or incorrect data
- Combine multiple datasets
- Reshape data between wide and long formats
- Prepare data for statistical analysis
