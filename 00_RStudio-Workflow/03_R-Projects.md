# R Projects in RStudio

## What is an R Project?

An **R Project** is a workspace that keeps the files and settings for one R project organised in one place.

An R Project is usually identified by a file with the extension:

```text
.Rproj
```

Imagine you are working on a research project called: Air Quality Analysis
You can create an R Project called: Air-Quality-Analysis

The folder may look like this:
Air-Quality-Analysis/
├── Air-Quality-Analysis.Rproj
├── data/
├── scripts/
└── output/

What does the .Rproj file do?

The .Rproj file tells RStudio:

"This folder is my project."

When you open the .Rproj file, RStudio opens the project and uses the project folder as the working environment.
